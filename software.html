▶Project 1: Secured Authentication Process for Physically Challenged People Using Morse Code and Machine Learning Algorithm

Objective: Developed a secure and accessible authentication system for individuals with motor disabilities using eye blinks to input Morse code as passwords.
Technologies Used: Implemented Haar Cascade algorithm for facial and eye detection, and Dlib library for tracking facial points and eye aspect ratio (EAR).

Challenges Addressed: Tackled issues such as time consumption of Morse code entry, visibility under low light conditions, and usability for individuals with partial blindness.
Achievements: Achieved high accuracy in real-time eye tracking and Morse code conversion, enhancing security and usability for physically challenged users.

▶Project 4: Chronic Kidney Disease (CKD) Prediction Using Machine Learning

Objective: Built a predictive analytics pipeline to detect Chronic Kidney Disease early using clinical and demographic data, enhancing healthcare decision-making.
Technologies Used: R, RStudio, caret, randomForest, e1071, xgboost, pROC, ggplot2, DataExplorer, dplyr, tidyr.
Features:

  • Processed Kaggle’s CKD dataset with 25 clinical and demographic features from 400 patients.
  • Performed EDA, feature correlation, and data cleaning with NA handling and categorical encoding.
  • Implemented and compared five ML models: Logistic Regression, Random Forest, SVM (RBF), XGBoost, and KNN.
  • Used 10-fold cross-validation and evaluated models with Accuracy, Precision, Recall, F1-Score, ROC-AUC.
  • Highlighted key indicators for CKD like serum creatinine, hemoglobin, hypertension, and age.
Challenges Addressed: Tackled class imbalance, improved model generalization, and ensured reproducible analysis via RMarkdown.
Achievements: Random Forest and XGBoost achieved the highest predictive performance, identifying CKD with strong accuracy and clinical alignment.
