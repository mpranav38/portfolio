# Personal Portfolio Website

A high-performance, responsive single-page portfolio website designed with an interactive retro-arcade aesthetic. It serves as a centralized node to showcase production-grade system architectures, machine learning models, and full-stack cloud applications.

---

## 🚀 Key Features & Interactive Architecture

### 1. Persistent UFO Celestial Background Mesh
Powered by a hyper-optimized single-loop HTML5 Canvas graphics engine (`js/canvas-effects.js`). 
* Features a responsive star field, meteor streams, and cursor-evading parallax planets.
* Includes an ambient, persistent dogfight simulator where a **Cyan UFO** (matching the core theme color) actively tracks and chases a high-velocity **Red UFO**.
* Designed with non-blocking laser ballistic systems that cleanly pass through target vectors to guarantee an infinite, 60fps frame cycle with zero interface stalling or edge locks.

### 2. High-Fidelity Performance Shard Intro Sequence
A performance-optimized vector shard canvas intro loop (`js/intro-animation.js`) that procedurally text-scans canvas pixels to render high-contrast geometric initials before cleanly shattering and fading into the main user view.

### 3. Core Portfolio Additions
* **Terminal Interface Simulator:** An automated interactive CLI terminal block that outputs professional skill-stacks on section visibility.
* **3D Card Parallax Tilt:** Mouse-tracking coordinate matrices mapped across skill tiles, timelines, and project nodes.
* **Cosmic Web Audio Engine:** Built-in synthesizer system creating click/implosion sound frequency pulses synced directly to UI hovers and canvas click events.
